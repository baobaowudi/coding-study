# 学习工作区

这里放真正的学习产出。

推荐结构：

- `exercises`：每周短代码练习
- `notebooks`：探索性 notebook
- `datasets/raw`：原始数据
- `datasets/processed`：清洗后的数据
- `notes/formulas`：数学和模型公式笔记
- `notes/weekly-reviews`：每周复盘
- `notes/paper-notes`：论文阅读笔记
- `experiments`：实验日志和结果表
- `projects`：可写进简历的项目
- `resume`：简历草稿和面试笔记

原则：如果某个结果不能从这里复现，就不要写进简历。
