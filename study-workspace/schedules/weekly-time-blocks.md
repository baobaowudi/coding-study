## 使用方法

每天开始前：

1. 打开 `PROGRESS.md` 看当前任务。
2. 复制 `daily-template.md` 到 `study-workspace/notes/daily/YYYY-MM-DD.md`。
3. 写清理论目标、代码目标、产出目标。

每天结束前：

1. 填写当天复盘。
2. 保存代码、notebook 或笔记。
3. 提交 Git commit。
