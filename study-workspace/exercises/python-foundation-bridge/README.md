# Python 基础桥接训练

这个阶段解决的问题是：你能想出中文思路，但不知道 Python 代码该怎么写。

原来的 30 道 Python 练习暂时后移。先用 7 天完成这里的桥接训练，再回到 `week-01-python` 里的 30 道题。

## 文件说明

- `python-cheatsheet.md`：中文思路到 Python 写法对照表
- `guided-examples.py`：完整示例，先读懂再仿写
- `fill-in-blanks.py`：半填空练习
- `tiny-tasks.md`：7 天极小任务清单
- `mistake-log.md`：记录不会写的语法和函数

## 每天流程

1. 读 2-3 个示例。
2. 改示例里的输入数据。
3. 做当天填空。
4. 仿写 1 个小函数。
5. 记录卡点。
