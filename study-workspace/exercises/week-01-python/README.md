# 第 1 周 Python 练习目录

目标：用 30 道小练习确认 Python 基础是否稳固。你已经完成 PDF 路线中的 Python 基础知识，但这里保留为求职学习仓库里的可见产出。

## 建议分组

- `01_string_list_dict.py`：字符串、列表、字典、集合，建议 10 题
- `02_function_class_file.py`：函数、类、异常、文件读写，建议 10 题
- `03_data_processing.py`：简单算法和数据处理，建议 10 题

题目清单见 `exercise-list.md`。三个 `.py` 文件已经提供函数入口，但没有提供答案；你需要自己实现并补测试样例。

## 完成标准

- 每个文件至少包含 10 个小练习或函数。
- 每个练习都能直接运行或有简单测试样例。
- 完成后在 `PROGRESS.md` 或周复盘里记录主要收获。

## 不需要过度投入

如果你已经能熟练写 Python，不要在这里停留太久。确认基础可用后，重点转入 NumPy、Pandas 和 EDA 产出。
