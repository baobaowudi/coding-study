# 30 道 Python 小练习清单

目标：确认 Python 基础足够支撑后续 NumPy、Pandas、PyTorch 学习。每道题都要自己写代码，不建议直接看答案。

## A. 字符串、列表、字典、集合

- [ ] 01. 反转字符串，并保留原字符串不变。
- [ ] 02. 统计一句话中每个字符出现次数。
- [ ] 03. 去掉列表中的重复元素，同时保留原顺序。
- [ ] 04. 找出两个列表的交集、并集、差集。
- [ ] 05. 将学生成绩字典按分数从高到低排序。
- [ ] 06. 统计一段文本中每个单词出现次数。
- [ ] 07. 找出列表中出现次数最多的元素。
- [ ] 08. 将嵌套列表拉平成一维列表。
- [ ] 09. 根据条件筛选列表中的偶数、奇数、正数。
- [ ] 10. 用列表推导式生成 1 到 100 的平方表。

## B. 函数、类、异常、文件读写

- [ ] 11. 写一个函数判断一个数是否为素数。
- [ ] 12. 写一个函数计算斐波那契数列前 n 项。
- [ ] 13. 写一个函数接收任意多个数字并返回均值。
- [ ] 14. 写一个装饰器统计函数运行时间。
- [ ] 15. 写一个 `Student` 类，包含姓名、成绩、是否及格方法。
- [ ] 16. 写一个 `GradeBook` 类，支持添加学生、计算平均分、找最高分。
- [ ] 17. 读取文本文件并统计行数、词数、字符数。
- [ ] 18. 将字典列表保存为 CSV 文件。
- [ ] 19. 从 CSV 文件读取数据并转换为字典列表。
- [ ] 20. 对用户输入做异常处理，保证输入必须是数字。

## C. 简单算法和数据处理

- [ ] 21. 实现冒泡排序或选择排序。
- [ ] 22. 实现二分查找。
- [ ] 23. 找出列表中的最大值、最小值、均值、中位数。
- [ ] 24. 对一组成绩做标准化处理。
- [ ] 25. 计算两个向量的点积。
- [ ] 26. 实现简单的 min-max normalization。
- [ ] 27. 从日志字符串中提取日期、等级和消息。
- [ ] 28. 合并两个用户行为记录列表，并按时间排序。
- [ ] 29. 对文本样本做简单清洗：去空格、转小写、去标点。
- [ ] 30. 写一个小型命令行菜单，能选择运行前面任意练习。

## 完成要求

- 每 10 道题放进一个 `.py` 文件。
- 每道题至少有 1 个测试样例。
- 做完后在 `PROGRESS.md` 的 Week 1 里勾选“完成 30 道 Python 小练习”。
